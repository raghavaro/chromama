Diagnostics

Two questions block the roadmap. Answer them before building anything on top.

1. Does move/group preserve discard?

Runs on its own scratch tabs in throwaway windows. Never touches yours. If this fails, reorganizing tabs would reload them and spike memory.

2. How much memory does a discard sweep reclaim?

Discards every eligible tab and measures system memory before/after. Touches your real tabs — but discarding is reversible: click a tab to reload it. System-wide measurement, so treat the number as directional.
